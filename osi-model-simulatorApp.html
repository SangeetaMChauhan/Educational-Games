📖 New to these words? Tap for a quick glossary
OSI Model
A 7-layer reference model that explains how data travels from one device to another across a network.
PDU
Protocol Data Unit — the name given to data at each layer (Segment, Packet, Frame, etc).
Encapsulation
Wrapping data with a new header at each layer as it goes down the stack to be sent.
Decapsulation
Removing each header, layer by layer, as data goes up the stack at the receiver.
Peer Layer
The matching layer on the other device — e.g. your Transport layer "talks" logically to the receiver's Transport layer.
Protocol
A set of rules that lets two layers (or two devices) understand each other.

📖 New to these words? Tap for a quick glossary
Protocol
A set of rules two computers agree on so they can understand each other — like a shared language.
IP Address
A unique number given to every device on a network — works like a home address for data.
Port
A numbered "door" on a device where a specific service listens, e.g. port 80 for websites.
Packet
A small chunk of data, wrapped with extra information, that travels across a network.
Client & Server
The client asks for something (like your browser); the server provides it (like a website's computer).
Router
A device that reads addresses and forwards packets toward the right network.

Mission 04 — Match the Ports

A computer can run many services at once — a web server, a mail server, a file server — all on the same IP address. Ports are numbered "doors" that keep them separate, so data reaches the right service. Tap a port, then tap the protocol that uses it.
